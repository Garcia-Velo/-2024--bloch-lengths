# Bloch lengths entanglement optimization

Code repository for the paper:

- Title: "Limitations of the marginal Bloch lengths in entanglement detection"

- Authors: A. García-Velo, M. Paraschiv, Y. Ban, E. Torrontegui and R. Puebla.

- DOI: https://arxiv.org/abs/2506.12406

Numerical code for the study of entanglement bounds in multipartite quantum systems, parametrized by **Bloch lengths** (norms of the reduced Bloch vectors of a density matrix). Given a target set of Bloch lengths, the code numerically optimizes over the compatible density matrices to find the states of extremal entanglement, and maps the resulting bounds across the physically valid region of Bloch-length space.

The two-qubit case is treated with the closed-form characterization of the valid Bloch-length region from Phys. Rev. A 109, 012423 (2024); the two-qutrit case uses a numerically-determined polytope, since the analytic inequalities are no longer tight in that setting.

## Repository structure

```
.
├── src/moments/        # Reusable package: core numerical routines
├── scripts/             # Standalone .py scripts that run the simulations behind the paper figures
├── examples/            # Guided Jupyter notebooks explaining the method step by step
├── tests/                # Notebooks validating the functions in src/moments
├── data/                 # Simulation outputs (.npz), mirrors the split below
│   ├── paper/            #   data used for the figures in the paper
│   ├── examples/         #   data generated by the notebooks in examples/
│   └── scripts/          #   data generated by the scripts in scripts/
└── plots/                # Generated figures, same three-way split as data/
    ├── paper/
    ├── examples/
    └── scripts/
```

**How the pieces fit together:**
- `src/moments` is the actual library: everything else imports from it.
- `scripts/two_qubits/` and `scripts/two_qutrits/` run the full optimization sweeps used in the paper and save results to `data/scripts` and `plots/scripts`.
- `examples/` mirrors the same physics with guided, documented notebooks (`two_qubits/`, `two_qutrits/`) that explain the space parametrization, discretization, and optimization steps in detail, writing to `data/examples` and `plots/examples`.
- `examples/paper_plots.ipynb` loads the curated results in `data/paper` and regenerates the exact figures used in the paper, saving them to `plots/paper`.
- `tests/` contains one notebook per module in `src/moments`, exercising its functions against known/hand-checked cases.

## Installation

Requires **Python ≥ 3.10**.

```bash
git clone https://github.com/Garcia-Velo/-2024--bloch-lengths.git
cd -2024--bloch-lengths
git checkout publication-2026

python3 -m venv .venv
source .venv/bin/activate        # on macOS/Linux

pip install -r requirements.txt
```

This installs the `moments` package defined in `src/` in editable mode, together with its dependencies (NumPy, SciPy, Matplotlib, ...). To run the notebooks in `examples/` and `tests/`, also install Jupyter:

```bash
pip install jupyterlab
```

## Usage

### Reproducing the paper figuresv

The curated data behind the published figures already lives in `data/paper`. To regenerate the figures from it:

```bash
jupyter lab examples/paper_plots.ipynb
```

### Re-running the simulations from scratch

To reproduce the underlying simulations (rather than only the plotting step), run the scripts directly:

```bash
python scripts/two_qubits/sym_plane.py
python scripts/two_qubits/xz_plane.py
python scripts/two_qutrits/sym_plane.py
python scripts/two_qutrits/xz_plane.py
```

Each script optimizes entanglement (via `moments.optimization.opt_moment_preserving_ent`) over a grid of physically valid Bloch lengths and saves the resulting `.npz` arrays and figures to `data/scripts` and `plots/scripts` respectively. Runtimes scale with the grid resolution (`D`) set inside each script.

Some points in the grid may give an incorrect result from the optimization or different from the paper plots. To solve this issue, it is required to rund the optimization a bigger number of times in those points.

### Learning the method

For a guided, annotated walkthrough of the same pipeline (space parametrization, grid discretization, optimization, saving), open the notebooks in `examples/`:

- `examples/two_qubits/sym_plane.ipynb`, `examples/two_qubits/xz_plane.ipynb`
- `examples/two_qutrits/polytope.ipynb`, `examples/two_qutrits/sym_plane.ipynb`, `examples/two_qutrits/xz_plane.ipynb`

Each notebook states in its introduction which paper figure(s) it reproduces.

### Running the tests

`tests/` contains one notebook per `src/moments` module, checking its functions against known or hand-derived cases:

```bash
jupyter lab tests/bloch.ipynb
```

(and similarly for `ent_meas.ipynb`, `initialization.ipynb`, `optimization.ipynb`, `quantum.ipynb`).

## Package overview (`src/moments`)

| Module | Contents |
|---|---|
| `bloch.py` | Generalized Pauli/Gell-Mann bases, tensor-product bases for multipartite systems, conversion between density matrices and Bloch vectors/norms, and the analytic bounds on the valid Bloch-length region. |
| `quantum.py` | Basic linear-algebra utilities (adjoint, etc.) and density-matrix validity checks. |
| `ent_meas.py` | Entanglement/mixedness measures: concurrence, entanglement of formation, binary entropy, partial transpose, trace norm, negativity. |
| `initialization.py` | Parametrization of density matrices (Cholesky-based) and routines to find an initial state matching a target set of Bloch lengths. |
| `optimization.py` | Core optimization routine (`opt_moment_preserving_ent`) that finds the state of extremal entanglement compatible with a given set of Bloch lengths, plus supporting gradient/loss machinery. |
| `saving.py` | Small utility to locate the project root (via `pyproject.toml`) so scripts/notebooks can save to `data/`/`plots/` using relative paths regardless of the working directory. |
