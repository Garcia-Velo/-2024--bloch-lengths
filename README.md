# [2024-] Bloch lengths optimization

This project aims to find the quantum states with maximum and minimum entanglement, given the set of second-order moments or Bloch lengths.
The code is structured to work with systems of any number of parties and local dimension.

- .gitignore: folders and files that git should ignore for commiting and pushing.
- README.md: this markdown file explaining the project.
- pyproject.toml: configuration file for the local instalation of the package moments.
- requirements.txt: dependencies for all libraries used.
- tree.tex: run to print the project structure (like above) or generate a ".txt" file.
- data: folder to store data generated by the experiments.
    - plots: folder to store the plots generated by the experiments. There will be the same folder structure as in experiments, and an extra folder for each experiment.
    - raw: folder to store the raw data generated by the experiments. There will be the same folder structure as in experiments, and an extra folder for each experiment.
- notebooks: this folder contains all Jupyter notebooks for all:  experiments and tests.
    - experimets: jupyter notebooks for the numerical experiments required for the work.
    - post: jupyter notebooks for the post-processing of the data generated in experimets.
    - test: implements tests to check that auxiliary code works properly. The test are incomplete but guive a rough idea.
- src: fhis folder contains reusable code for the different Jupyter notebooks. All is located inside the "moments" folder, to generate th elocal library "moments".
    - moments/bloch.py: functions to manage the global and local Bloch vector and Bloch lengths.
    - moments/initialization.py: functions required for generating and parametrizing density matrices with given Bloch lengths.
    - moments/quantum.py: functions to generate and validate density matrices, and implementing several entanglement measures.
    - moments/saving.py: functions for saving data and managing paths. They generate the folder structure inside the data folder.
